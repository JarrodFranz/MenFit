# MenFit fork design

*Date: 2026-09-07. Status: approved by the owner in conversation.*

## Goal

Create MenFit, a men's training-and-nutrition app, by forking FemFit
(`D:\Documents\Claude\Projects\Female running app`, package `femfit_app`,
forked at commit `13e91b9`). Version 1 is a faithful fork: everything FemFit
has minus menstrual-cycle features, rebranded, re-themed, and reordered to be
strength-first. No new men-specific features in v1.

Supporting audit with file-level detail: `docs/femfit_fork_audit.md`.

## Decisions taken with the owner

| Decision | Choice |
|---|---|
| Positioning | Strength-first; GPS running/walking/cycling kept as a full but secondary feature |
| Wellbeing tab | Kept, renamed **Recovery** |
| Identity | Display name **MenFit**, Dart package `menfit_app`, app id `com.jarrodfranz.menfit`, DB file `menfit` |
| Visual direction | **Forge**: charcoal surfaces, burnt-orange accent |
| v1 scope | Faithful fork; men-specific additions go on the roadmap |
| Fork mechanics | Subtractive copy of the FemFit tree with a fresh git history |
| Database | Schema reset to v1, no migration chain |
| Sex field | Not added; the app assumes a male user, documented in `knowledge/domain/mens_health.md` |
| Safety / live tracking | Kept unchanged (not gendered in code) |

## Approach

Subtractive fork. Copy the FemFit working tree (excluding `build/`,
`.dart_tool/`, `.idea/`, `scratch/`, secrets, the business plan and the old
task tracker), delete the cycle module, fix every compile error the deletion
exposes, rename the package in one sweep, reset the schema, re-theme, rewrite
copy and docs. The existing architecture guard tests
(`domain_import_guard_test.dart`, the identity guards) make stragglers
mechanical to find.

Git: `git init` in `D:\Documents\Claude\Projects\MenFit`, single initial
commit whose message records the FemFit source commit, pushed to
`https://github.com/JarrodFranz/MenFit` on `main`.

## Identity and branding

  `package:menfit_app/` (about 4,400 lines across lib/ and test/).

  package dir moves to `com/jarrodfranz/menfit/`; manifest label `MenFit`.
- iOS: all `PRODUCT_BUNDLE_IDENTIFIER` values become `com.jarrodfranz.menfit`
  (and `.RunnerTests`); `CFBundleDisplayName` / `CFBundleName` `MenFit`.

- In-Dart: bootstrap app name, `env.dart` default app name and proxy header
  `X-MenFit-Key`, method channel `com.menfit.app/wearables`, map
  `userAgentPackageName` `com.menfit.app`, GPX creator `MenFit`, export
  filename prefix `menfit-`, `driftDatabase(name: 'menfit')`.
- Splash widget renamed `MenFitSplashScreen`; error copy "MenFit export".
- Assets: new placeholder `menfit_logo.png`, `menfit_logo_solid.png`,
  `menfit_splash.png`, `app_icon.png` generated by a script in the Forge
  palette (wordmark on charcoal). Android and iOS icon sets regenerated from

- Guard tests updated to assert the new identity:
  `app_identity_guard_test.dart`, `ios_infoplist_guard_test.dart`,

- Deploy tooling renamed: `tools/menfit_deploy/`, `distribution/android.json`,

  scripts. The FatSecret proxy backend is app-agnostic and is copied

## Navigation and Home

Five-tab shell: **Home, Train, Nutrition, Recovery, Settings**.

- **Train** is FemFit's Activity branch with the route path kept as
  `/activity` (avoids churn in typed routes) and the tab label and icon
  changed to Train / fitness-centre icon. The exercise hub defaults to the
  strength type. The tab's primary action is "Start workout" for the active
  strength cycle (mesocycle) when one exists, otherwise "Start a routine".
  "Record GPS activity" remains a visible secondary action.
- **Home** card order: Today's session (active strength cycle: routine name,
  week X of Y, first exercises; tapping opens the strength tracker), Streak,
  Macros today, Water quick-add, Recent achievement, Insight discovery,
  Progress summary. FemFit's Today sheet loses its period tile.
- **Recovery** is the Wellbeing branch renamed: route `/recovery`, screen
  title "Recovery", tab icon self-improvement/spa.

## Recovery domain changes

- `SymptomType`: remove `pelvicPain`; keep `cramping` with label "Muscle
  cramps"; keep `bloating`. All other symptoms unchanged.
- `FlareCategory`: replace `endometriosis`, `periodSymptoms`, `pelvicPain`
  with `injury`, `illness`, `migraine`, `backPain`, `other`. Storage strings
  are the enum names; because the schema resets there is no legacy data to
  migrate. `fromStorage` falls back to `other` for unknown strings.
- Streak protection sources: manual recovery days and protecting flares.
  Copy: "Recovery day protected", never "period".
- Insights keep the day-of-week, hydration, protein and wellbeing evaluators.

## Nutrition changes

- `energy_estimate.dart`: Mifflin-St Jeor uses the male constant (+5). The
  dartdoc states the app's population is men and no sex is collected.
- `micronutrient_adequacy.dart` reference intakes (adult male, DRI):
  iron 8 mg, calcium 1000 mg, vitamin D 15 mcg, fibre 38 g, vitamin C 90 mg.
  The `cyclePhase` field and menstrual context banner are removed.
- `micronutrient_info_sheet.dart` becomes "Micronutrients & Recovery":
  iron for endurance athletes (foot-strike haemolysis, sweat loss), calcium
  and vitamin D for bone stress, fibre. Same not-medical-advice disclaimer.
- `knowledge/research/micronutrient_adequacy.md` and
  `nutrition_energy_estimates.md` are rewritten with the male values and
  their sources.
- Macro targets, locks, calorie target logic: unchanged apart from doc
  references to `womens_health.md` → `mens_health.md`.

## Theme (Forge)

- `AppTheme._seed = Color(0xFFD84A1B)`; dark-mode accent derived by Material
  3 `fromSeed` (target around `0xFFFF6D3A`). Light surface tint warm
  off-white (`0xFFFAF8F5`), dark surface near-black (`0xFF121212`).
- Colour-blind seeds unchanged (they are accessibility overrides, not brand).
- `AppTokens`: `success`, `warning`, `intensity*` kept; `cyclePhase*` removed
  from the constructor, every palette tuple, `copyWith` and `lerp`.
- Share-card themes: `signatureOrchid` → `forgeDark` (default), plus
  `forgeLight`, `clean`. Tagline: "Built for the work · MenFit".
- Onboarding pitch: "A training and nutrition companion built around how men
  actually train, recover and progress."
- Doc-comment pronoun sweep: she/her → they/them or "the user".

## Database

- `schemaVersion = 1`; `onCreate` creates all tables; `onUpgrade` body
  removed. Tables: activities, activity_samples, badge_awards, challenges,
  daily_checkins, daily_step_totals, flare_events, foods, nutrition_entries,
  nutrition_goals, recovery_days, routes, strength tables, user_profiles,
  water_logs, weight_logs, wellbeing_events, yoga_sequences.
- Migration tests replaced by one v1 creation test asserting every table and
  index exists. `knowledge/troubleshooting/database_migrations.md` kept as
  guidance for the fork's own future migrations.

## Knowledge, docs and tooling

- `knowledge/` copied. Rewritten: `product/product_vision.md`,
  `product/target_users.md`, `product/terminology.md`,
  `engineering/security_and_privacy.md` (S3 tier becomes health check-in,
  body-weight and location data), `architecture/data_architecture.md` streak
  section, `domain/fitness.md`, `domain/nutrition.md`, `domain/running.md`.
- `domain/womens_health.md` replaced by `domain/mens_health.md` carrying the
  same rules: no medical claims, evidence-gating for any physiology-based
  recommendation, opt-in health features, plus the male energy/RDA basis.
- Every source citation of `womens_health.md` repointed.
- New ADR `017_fork_from_femfit.md`: origin commit, what was removed, schema
  reset rationale, identity.
- `CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, `README.md`, `.claude/agents/*`,
  `.claude/skills/*` rewritten for MenFit; `stall_watchdog.ps1` and the
  one-`flutter test`-at-a-time rule carried over.
- Not carried over: `female_fitness_business_plan.html`, `TASKS_TO_DO.md`,
  `scratch/`, `Deployments/`, `handoff/` (MenFit has its own).
- New `TASKS_TO_DO.md` with a short roadmap: owner-side distribution setup,
  real artwork, and parked men-specific ideas (1RM estimates, body-fat
  tracking, bulk/cut calorie targets).

## Testing and definition of done

- `dart run build_runner build`, `dart format .`,
  `flutter analyze --fatal-infos`, `flutter test` all clean, run centrally,
  one test process at a time. Expected suite size roughly 3,300 tests; the
  exact count is reported, never estimated.
- `flutter build apk --release` with the staging env produces package
  `com.jarrodfranz.menfit` labelled MenFit.
- Widget tests updated for the five-tab shell, Recovery naming, Home card
  order and Train hub default.
- Tree pushed to `main` on the MenFit repo with `handoff/` current.

## Out of scope for v1

Sex/gender field, new men-specific features, real brand artwork, store
listings and privacy policy hosting, Windows MSIX identity.
