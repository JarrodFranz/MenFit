# Troubleshooting

Diagnosed problems and their fixes. When you solve a non-obvious build, platform, package, or tooling problem, record it here so no future session re-diagnoses it.

Conventions:
- One file per problem area (e.g. `windows_build.md`, `web_wasm.md`, `drift_migrations.md`) — append entries rather than creating near-duplicates.
- Entry format: **Symptom** (exact error text), **Cause**, **Fix**, **Date/versions**.
- Platform behaviour quirks that aren't "problems" belong in `../flutter/platform_notes.md`.
